# 경계 파일(폴리곤) 사양

지도에 동 폴리곤을 그리려면 **동 경계 GeoJSON** 파일 1개가 필요합니다.
점포 주소가 **지번주소(= 법정동)** 이므로 **법정동 경계**를 권장합니다. (자동 매칭률 ≈ 99%)

## 1) 형식: GeoJSON FeatureCollection

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "properties": { "EMD_KOR_NM": "인계동", "sgg_nm": "팔달구" },
      "geometry": { "type": "Polygon", "coordinates": [ [ [127.03,37.27], ... ] ] }
    }
  ]
}
```

- 좌표계는 **WGS84 경위도(EPSG:4326)** — `[경도, 위도]` 순서.
- 동 이름 속성은 아래 중 아무 이름이나 되면 자동 인식합니다:
  `EMD_KOR_NM`, `adm_nm`, `EMD_NM`, `HANG_NM`, `DONG`, `dong`, `행정동`, `법정동`, `name` …
  값이 `"경기도 수원시 팔달구 인계동"` 처럼 전체주소여도 마지막 토큰(인계동)을 사용합니다.
- 구 속성(선택): `sgg_nm`, `SIG_KOR_NM`, `gu` … 같은 이름의 동이 여러 구에 있을 때 구분에 사용.
- `Polygon` / `MultiPolygon` 모두 지원.

## 2) 불러오기

- **자동**: 파일명을 `data/suwon_hjd.geojson` (또는 `data/hjd.geojson`, `data/dong.geojson`)로 두면
  웹서버로 열 때 자동 로드됩니다.
- **수동**: 지도 화면 위로 파일을 **드래그&드롭** 하거나 “파일 선택” 버튼으로 불러옵니다.
  (index.html 을 파일로 직접 열면 브라우저 보안상 자동 로드는 안 되고 드래그&드롭만 됩니다.)

## 3) (선택) 연계표 — 이름이 다른 소수 케이스 보정

주소가 **행정동으로 입력**돼 법정동 경계와 이름이 다른 소수 점포(예: 광교1동, 행궁동)는
`동 이름 → 대상 경계동 이름` 연계표로 보정합니다. 기본값이 앱에 내장돼 있고, 추가/수정 시
아래 JSON을 드래그&드롭 하면 됩니다.

```json
{
  "광교1동": "이의동",
  "광교2동": "하동",
  "행궁동":  "북수동"
}
```

또는 배열 형태:

```json
[ { "gu": "영통구", "beopjeong": "이의동", "haengjeong": "광교1동" } ]
```

## 참고: 공개 경계 데이터

- 국가공간정보포털(법정구역: 리·동 SHP) → GeoJSON 변환
- 통계청 SGIS 행정구역 경계
- GADM / 오픈데이터 저장소의 대한민국 읍면동 GeoJSON
